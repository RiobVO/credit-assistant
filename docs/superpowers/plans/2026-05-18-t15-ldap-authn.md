# T1.5 — LDAP/OAuth AuthnAdapter (CA-020) — LDAP only

> Scope сужен в pre-impl: только LDAP. OAuth defer'ится в backlog как **T1.5b**.
> Pilot-bank LDAP-параметры пока неизвестны → generic AD defaults в docs.

## Decisions (approved 2026-05-18)

- **LDAP only** в T1.5; OAuth — backlog T1.5b post-pilot.
- **`AUTHN_MODE=seeded|ldap` env switch** (default `seeded`). Один adapter активен на инсталляцию.
- **Break-glass через email whitelist**: `ADMIN_BREAK_GLASS_EMAILS=admin@bank.uz,emergency@bank.uz` — даже в `AUTHN_MODE=ldap` для этих email'ов работает SeededAdapter (local bcrypt check).
- **Library: `ldap3`** — pure Python, нет system deps в Docker, async через `asyncio.to_thread`.
- **Lazy upsert при первом LDAP bind** — `analysts.password_hash` становится NULLABLE, добавляется `authn_source VARCHAR(20) NOT NULL DEFAULT 'seeded'` (enum: `seeded`/`ldap`/`break_glass`).
- **Mock-only unit tests** — testcontainers-openldap defer'ится в T1.5b. Production будет с реальным LDAP, mock покрывает adapter logic.
- **Generic AD defaults** в `docs/operations/ldap-setup.md` — sAMAccountName login, `CN=Users,DC=bank,DC=uz` пример base DN, memberOf for groups.

## Atomic split

### T1.5.1 — LDAP adapter + Settings + DI switch (~12 файлов)

**Файлы:**
1. `src/config/settings.py` — `authn_mode`, `ldap_uri`, `ldap_base_dn`, `ldap_bind_dn`, `ldap_bind_password`, `ldap_user_search_filter`, `ldap_group_search_filter`, `ldap_role_analyst_group`, `ldap_role_senior_analyst_group`, `admin_break_glass_emails`.
2. `pyproject.toml` — `ldap3` в production deps.
3. `src/infrastructure/auth/ldap_client.py` — `LdapClient` обёртка над `ldap3.Connection` с `asyncio.to_thread` + `LdapBindError`/`LdapSearchError`.
4. `src/infrastructure/auth/ldap_authn_adapter.py` — implements `AuthnPort`. bind → search → groups → AnalystIdentity. Lazy upsert делегируется в analyst_repo (вшит через DI).
5. `src/infrastructure/auth/break_glass_authn_adapter.py` — composite: email в whitelist → SeededAdapter, иначе → LdapAdapter. Возвращает `AnalystIdentity` с пометкой источника через side-channel (audit-log payload в T1.5.3).
6. `src/interfaces/api/bank/dependencies.py` — `get_authn_adapter` switch по `settings.authn_mode`. В `seeded` mode возвращает SeededAuthnAdapter напрямую. В `ldap` mode — BreakGlassAuthnAdapter(seeded, ldap).
7. `src/infrastructure/auth/ldap_authn_adapter_test.py` — unit tests с `unittest.mock` для ldap3.Connection: happy path, bind fail, user not found, group not matched.
8. `src/infrastructure/auth/break_glass_authn_adapter_test.py` — unit tests: break-glass email → seeded, обычный email → ldap, оба source возвращают identity.
9. `docs/adr/0019-ldap-authn.md`.

**TDD цикл:**
- Red 1: `ldap_authn_adapter_test.py::test_successful_bind_returns_identity` — mock Connection.bind/search возвращает user entry, adapter возвращает AnalystIdentity.
- Green: minimal LdapAuthnAdapter.
- Red 2: `test_failed_bind_returns_none` — bind raises LdapBindError → return None.
- Red 3: `test_user_not_in_required_group_returns_none`.
- Red 4: `break_glass_test::test_email_in_whitelist_uses_seeded`.
- Red 5: `break_glass_test::test_email_not_in_whitelist_uses_ldap`.

**Verify:** `uv run pytest src/infrastructure/auth/` + ruff + mypy. Без БД migration — нет integration tests.

**Commit:** `feat(auth): T1.5.1 LdapAuthnAdapter + break-glass + AUTHN_MODE switch`.

## Out of scope (явно)

- **OAuth2/OIDC** → T1.5b backlog.
- **openldap testcontainer integration tests** → T1.5c backlog.
- **Group → role mapping configurable beyond 2 groups** (analyst/senior_analyst) — пока hardcoded 2 группы; admin role будет добавлен через T3+ admin-management.
- **LDAP cache** — каждый login делает свежий bind+search. Кэширование (если станет узким горлышком) — отдельно.
- **MFA для LDAP-users** — TOTP остаётся через `mfa_secret` колонку, не меняется. LDAP только заменяет первый factor (password verification).
